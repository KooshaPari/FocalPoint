# Wave1 W1-15: 2026 Rust Ecosystem Release Notes Summary

> Date: 2026-06-13
> Sources: Official release notes, changelogs, and GitHub releases for each project.

---

## rustc

**2026 Releases:** 1.94.0 (Mar 5), 1.95.0 (Apr 16), 1.96.0 (May 28)

- **1.96.0** (May 28, 2026): Key additions include `char::MIN`, `char::MIN_VALUE`, and `char::MAX_VALUE` constants; stabilization of `Vec::pop_if` and `UnsafeCell::as_mut_ptr`; a new `char::to_ascii` method; const-stability of `ManuallyDrop::new`; `unbounded_shl` / `unbounded_shr` for integer types; and `read` / `read_exact` / `read_buf` moved to `std::io::Read` at the core level. Several const-eval features and panic-in-const improvements landed.
- **1.95.0** (Apr 16, 2026): Major stabilization of `fn` pointers in `const` contexts (`const fn` calling `fn` pointers), const `unwrap`/`expect` for `Option` and `Result`, `const trait` bounds in `impl` blocks, `const` `Vec::resize`, and `const` `From`/`Into` for `Option` and `Result`. Also stabilized `const` `mem::offset_of` and `const` `Cell::get_mut`.
- **1.94.0** (Mar 5, 2026): Stabilized `const` `Vec::resize_with`, `const` `Option::unwrap_or_default`, and `const` `Result::unwrap_or_default`. Added `const` `mem::size_of_val` and `const` `mem::align_of_val`. `const` `Cell::as_mut` was stabilized. Also included improvements to `const` `unsafe` blocks and `const` `fn` pointer comparisons.

## cargo

**2026 Releases:** 1.94 (Mar 5), 1.94.1 (Mar 26), 1.95 (Apr 16), 1.96 (May 28)

- **1.96** (May 28, 2026): Stabilized `target.'cfg(..)'.rustdocflags` in config; manpage support for nested subcommands (`cargo help report future-incompat`). Security fixes for CVE-2026-5223 (medium, tarball symlink extraction) and CVE-2026-5222 (low, auth with normalized URLs). Fixed regressions in git submodule URLs and non-default refspecs. Added new crate `cargo-util-terminal` for terminal rendering utilities.
- **1.95** (Apr 16, 2026): Forbade `cargo init` in the home directory. HTML timing report now uses SVG rendering (canvas removed). Improved error messages to follow rustc diagnostic style. Added `--dev`/`--build`/`--target` suggestions in `cargo remove`. Fixed `cargo test --frozen` downloading unnecessary dependencies. Many `cargo-lints` additions (non-kebab-case bins, missing lints inheritance, unused workspace deps/fields, redundant homepage/readme).
- **1.94.1** (Mar 26, 2026): Security fixes for CVE-2026-33055 and CVE-2026-33056 (malicious crate tarball extraction altering permissions on arbitrary paths). Fixed FreeBSD certificate behavior by downgrading libcurl.
- **1.94** (Mar 5, 2026): Stabilized `include` config key for loading extra config files. Stabilized `pubtime` field in registry index for time-based resolution. Cargo now parses TOML v1.1 for manifests and config. `CARGO_BIN_EXE_<name>` now available at runtime. SVG timing report option added. Performance optimizations for `cargo clean` and `cargo locate-project`.

## tokio

**2026 Releases:** 1.49.0 (Jan 3), 1.50.0 (Mar 3), 1.51.0 (Apr 3), 1.52.0 (Apr 14), 1.52.1 (Apr 14), 1.52.2 (May 4), 1.52.3 (May 8)

- **1.52.3** (May 8, 2026): Fixed mpsc channel `len()` underflow, `OwnedPermit::release()` notification, `RwLock` requiring `max_readers != 0`, and `try_recv()` returning `Empty` when closed with outstanding permits.
- **1.52.2** (May 4, 2026): Reverted LIFO slot stealing from 1.51.0 due to performance regressions.
- **1.52.1** (Apr 14, 2026): Reverted `spawn_blocking` sharded queue change to fix a hang regression.
- **1.52.0** (Apr 14, 2026): Added `AioSource::register_borrowed` for I/O safety; `try_io` for unix pipe sender/receiver; stabilized `LocalRuntime`; added `runtime::worker_index()` and runtime name; added `io_uring` support in `AsyncRead` for `File` (unstable); improved `spawn_blocking` scalability (later reverted); improved worker queue `compare_exchange_weak`.
- **1.51.0** (Apr 3, 2026): Stabilized `LocalRuntime`; added `runtime::worker_index()` and runtime name; added `get_peer_cred` on Hurd; wasm32-wasip2 networking support. Changed runtime to steal tasks from LIFO slot (later reverted due to perf issues).
- **1.50.0** (Mar 3, 2026): Added `TcpStream::set_zero_linger`; `is_rt_shutdown_err`; vectored writes for `write_buf`; optimized `memchr` in-bounds hint; improved `AsyncFd` cleanup on deregister; fixed `spawn_blocking` double increment on shutdown; improved `current_thread` scheduler parking.
- **1.49.0** (Jan 3, 2026): Added `TCLASS` option on IPv6; stabilized `runtime::id::Id`; `JoinSet::Extend`; `LocalSet::id()`. Deprecated `set_linger` in favor of `set_zero_linger`. Fixed `join!`/`try_join!` hygiene issues; reverted manual vtable replacement with `Wake`.

## axum

**2026 Releases:** 0.8.9 (Apr 14), axum-extra 0.12.6, axum-macros 0.5.1

- **0.8.9** (Apr 14, 2026): Added `WebSocketUpgrade::{requested_protocols, set_selected_protocol}` for flexible subprotocol selection. Updated minimum Rust version to 1.80. Fixed `MethodRouter` connect endpoint field and multipart body limit error message.
- **axum-extra 0.12.6** (Apr 14, 2026): Security fix: escape backslashes and double quotes in `Content-Disposition` filenames in `Attachment` and `FileStream` to prevent header injection. `vpath!` macro now rejects deprecated `:var` and `*var` path variables, enforcing `{var}` only. Fixed multipart body limit error message.
- **axum-macros 0.5.1** (Apr 14, 2026): Fixed compilation error when deriving `TypedPath` with `OptionalFromRequestParts` in scope.

## sqlx

**2026 Releases:** 0.9.0 (May 6)

- **0.9.0** (May 6, 2026): Major release with MSRV bumped to 1.94.0.
  - **New `sqlx.toml` config format:** per-crate configuration for `DATABASE_URL` renaming, global type overrides, migration table renaming, and migration hash ignore characters. Feature-gated under `sqlx-toml`.
  - **Breaking:** Significant changes to `Migrate` trait; `sqlx::migrate::resolve_blocking` is now `#[doc(hidden)]`. `RawSql` lifetime fixes (adds `DB` type parameter). `Migrator::set_ignore_missing` and `set_locking` now return `&mut Self`. Postgres: force generic plan for better nullability inference (may change `query!` macro output). `Decode`/`Encode`/`Type` implemented for `Box`, `Arc`, `Cow`, `Rc`. `Cow` now always decodes `Cow::Owned`. `SqlSafeStr` trait added to `query*()` functions as a safety speedbump against `format!()` injection. `libsqlite3-sys` versioning now uses a SemVer range. SQLite extension loading is now `unsafe`. `SqliteValue` is now `!Sync` and `SqliteValueRef` is `!Send` to prevent data races. `MySqlConnectOptions::charset`/`collation` imply `set_names(true)`.
  - **Added:** Nested Postgres domain types; `PgBindIter` for encoding; `Arc<str>`/`Arc<[u8]>` support; `runtime-smol` and `runtime-async-global-executor` features replacing `async-std`; compile-time support for external drivers; SQLite extensions in macros and CLI; exclusion violation error kind; `no_tx` migration support; `Migrator::with_migrations()`; skip-migrations support; `Json::into_inner()`; `PgNotification` clone.
  - **Fixed:** Correct `ROLLBACK` on dropped transaction during `BEGIN`; SQLite transaction level accounting; null decoding regression; smarter `.env` loading and caching; macOS runner deprecation; deterministic migration order; JSONB decoder panic; MySQL truncated OK packet panic; Postgres advisory lock cancel safety; SCRAM password `SASLprep`; SQLite `from_utf8_unchecked` replaced; SQLite custom collation invalid UTF-8 handling; potential deadlock in `StdSocket::poll_ready()`; many more.
  - **Organization:** Repository moved to `transact-rs` GitHub organization. `Cargo.lock` removed from tracking.
