# Changelog

## [0.1.0] - 2026-06-12

### Added
- Initial release of pheno-ci-templates.
- Canonical reusable CI workflow (`ci.yml`) for Rust, Python, Go, Node.
- Canonical reusable release workflow (`release.yml`) for crates.io, npm, PyPI, Go.
- Language auto-detection via `hashFiles()` against manifest files.
- Input defaults and pass-through secrets for caller convenience.
- AI-DD crutch files: AGENTS.md, llms.txt, WORKLOG.md, CHANGELOG.md, LICENSE-MIT.
